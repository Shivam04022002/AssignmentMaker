# HandWrite

Turn your text into handwritten pages. React Native (bare, JavaScript only) app for Android and iOS.

## Run

```sh
npm install
npm start            # Metro
npm run android      # build + install on a device/emulator
cd ios && bundle install && bundle exec pod install && cd .. && npm run ios   # macOS only
```

```sh
npm test             # Jest
npm run lint         # ESLint
```

## Architecture

```
Document data (plain text + options)   ← the only source of truth
      ↓
Text editor (TextInput + patch-based undo/redo)
      ↓
Handwriting renderer (layoutHandwriting → HandwritingText)
      ↓
Paper canvas (PaperCanvas: paper, grain, ruling, handwriting layers)
```

| Path | Purpose |
| --- | --- |
| `src/data/handwritingStyles.js` | Handwriting style registry (`registerHandwritingStyle`) |
| `src/data/pens.js`, `src/data/paper.js` | Pens, page types and page metrics (line spacing lives here) |
| `src/models/document.js` | Document shape, defaults, validation |
| `src/storage/documentStorage.js` | Local persistence (AsyncStorage, swappable backend) |
| `src/utils/textLayout.js` | Pure text → handwriting layout model and baseline maths |
| `src/utils/textHistory.js`, `src/hooks/useTextHistory.js` | Undo/redo |
| `src/components/` | `HandwritingText`, `PaperCanvas`, selectors, `EditorToolbar`, icons |
| `src/screens/` | Home, New Document, Editor |

Key decisions:

- **Logical page.** Pages are laid out at a fixed 360-unit width and scaled to the screen, so text wraps identically on every device (and later exports can reuse the same layout).
- **Ruled alignment.** Each line of writing is a row exactly one ruled line tall (lines are pre-broken by the layout engine), so writing locks onto the ruling. Glyph baselines are placed using each font's measured metrics (`metrics` in the style registry).
- **Natural variation** (tilt, baseline wander, size, spacing, ink pressure, per-letter jitter for print styles) is seeded from the word and the document id: stable while typing and identical every time a document is opened.

### Handwriting engine (Phase 2)

- **Line breaking** happens in `textLayout.js` using glyph advance widths measured from the font files (`src/data/fontMetrics.js`, generated by `node scripts/extract-font-metrics.js`). Long words split at natural points (`/`, `-`, `.`) or get a hyphen; closing punctuation never starts a line; extra typed spaces widen the gap; blank lines become one ruled line of paragraph spacing.
- **Variation** is seeded from document id · page id · text position (word + occurrence) · character index (`src/utils/variation.js`), never `Math.random()`. Repeated words and letters each get their own shape; editing one word does not re-jitter others.
- **Ink**: per-pen strength, floor and a faint bleed halo (`src/data/pens.js`); letters vary slightly in strength, never below the floor.
- **Tuning**: every style is defined in `src/data/styleCatalog.js`. In development builds, long-press the **HandWrite** title on Home to open the Handwriting Tuner (live preview with baseline/x-height guides, steppers, "Share config" to copy values back).

### Handwriting styles (Phase 3)

30 styles in five categories (Student, Casual, Formal, Cursive, Stylish), each with its own font.

| File | Purpose |
| --- | --- |
| `src/data/styleCatalog.js` | The catalogue: one data entry per style (font, category, personality, optional explicit values) |
| `src/data/handwritingPersonality.js` | The single shared mapping from personality traits (consistency, speed, pressure, slant, roundness, spacing, baselineMovement, sizeVariation) to engine parameters |
| `src/data/handwritingStyles.js` | Registry: completes entries (measured metrics, x-height normalisation capped so lines can't collide, personality, clamps), search/filter, aliases, tuning overrides |
| `src/storage/preferencesStorage.js` | Favourite and recently used styles (local, persisted) |
| `src/components/HandwritingStyleSelector.js` | Picker: search, category/favourites/recent filters, recently-used strip, two-column live previews |

The original ids `neat`, `casual`, `cursive`, `rounded` and `fast` are unchanged (and keep their Phase 2 tuning), so existing documents open as before. `STYLE_ALIASES` maps alternative ids for future renames; unknown ids fall back to `neat`.

### Realism (Phase 4)

Calibrated against reference scans of handwritten assignment pages (kept in `reference/` for development only — never bundled):

- **Writing size** — x-height ≈ 0.29 of the rule pitch (about 50–60 characters per line); x-height is measured as the median of the flat-topped lowercase letters; `fontSize` per style corrects perceived size.
- **Letter shape** — every letter gets its own tiny width, height, lean, shift and gap; words a tiny horizontal stretch (`handwritingPersonality.js`). Joined scripts only vary in ink.
- **Ink** — no glow: a hairline horizontal copy thickens downstrokes but not connecting strokes; pressure thins slightly along each word.
- **Realism presets** (`src/data/realismPresets.js`) — Realistic Student / Exam / Notes / Assignment rescale spacing and variation; chosen per category.
- **Paper templates** — Blank, Blue Ruled, Ruled + Margin (`lined`), Wide Ruled, Narrow Ruled, with double red margin and header rule; text always starts after the margin, and glyph size is capped per template so lines never collide.
- **Formatting** — headings (larger, firmer, optional hand-drawn underline), underlines and labels (`Q1.`, `Ans:`, `1.`, `•` detected automatically, with hanging indents) are stored as character ranges in `document.formatting` (`src/utils/formatting.js`) and follow the text through edits and undo/redo. In the editor's text panel: **H** cycles heading / heading without underline / none; **U** underlines the selection or word.
- **Tuner** — paper, pen, preset, style parameters, pressure, ink strength, paper line/grain opacity and margin position, plus a **Compare** mode that loads a reference image from the Metro dev server (or any URL/path).

**Visual preview without a device**: `scripts/visual-preview.js` renders the real layout model to HTML (same fonts, geometry and transforms) for screenshots in a desktop browser:

```sh
VISUAL_OUT=/tmp/hw VISUAL_ALL=1 VISUAL_SHEETS='[]' npx jest --testRegex 'scripts/visual-preview\.js$'
chrome --headless=new --allow-file-access-from-files --screenshot=all.png file:///tmp/hw/all.html
```

### Pages and export (Phase 5)

- **Model** — the document text stays one string (undo/redo and formatting ranges span it). A page break (``) separates pages the user created with *Add Page*; `pageIds[i]` names page *i* and seeds its handwriting (so reordering never re-jitters a page). Old single-page documents simply have no breaks and open unchanged. `normalizeDocument` also accepts `{ pages: [{ id, content, formatting }] }`.
- **Automatic flow** (`src/utils/pagination.js`) — each page's text is laid out by the handwriting engine and its *lines* are dealt onto physical pages by how many ruled rows fit; a long page continues on the next sheet. Breaks never split a line, never leave a heading alone at the bottom, and continuation pages don't start with blank lines.
- **Page operations** (`src/utils/pageOps.js`) — add, delete, move left/right. Operating on a continuation page first splits it off at its exact layout boundaries, so it acts on precisely the text you see.
- **Editor** — `‹ Page 2 of 5 ›` bar, *Pages* overview (thumbnails drawn by the same `PaperPage` renderer in preview quality), optional handwritten page numbers on the paper.
- **Export** (`src/export/`) — PDF (all pages), PNG/JPG (current page or every page, `HandWrite_<title>_page-01.png`). `ExportRenderer` mounts one page at a time with the editor's own `PaperPage`; the in-app native module `modules/handwrite-export` (autolinked; Kotlin + Objective-C) draws that view into an Android `PdfDocument` (vector text) or a bitmap (A4 at 150 dpi, recycled per page) and shares through a `FileProvider` / `UIActivityViewController`. No third-party export libraries.

### Freehand ink (Phase 6)

- **Tools** — *Text* (typed handwriting, as before), *Pen* (blue/black, 1–8 px, 50–100 % opacity), *Marker* (yellow, blue, pink, green; 12–20 px, semi-transparent), *Eraser* (small/medium/large). The options for the active tool sit above the toolbar.
- **Data, not pixels** (`src/ink/strokes.js`) — strokes are stored per rendered page (`document.ink[pageKey]`, `pageKey = pageId#chunk`) in *page coordinates*, as flat point arrays. Touch points are converted with `screenToPage`, so strokes stay put at any display size and export exactly.
- **Input** (`src/ink/DrawingSurface.js`) — React Native's `PanResponder`; jitter filtering, light corner-preserving smoothing and simplification; a second finger cancels. Stylus pressure (`force`) varies pen width (75–125 %) only when the device reports varying pressure.
- **Rendering** (`src/ink/InkLayer.js`, react-native-svg) — layers: paper → marker → typed handwriting → pen. Same-style pen strokes share paths (thousands of strokes → a few native elements); each highlight is its own path so overlaps deepen. Thumbnails use simplified geometry. Export draws the same layers.
- **Eraser** — cuts freehand strokes where it passes (never typed text). One gesture = one undo step.
- **History** (`src/hooks/useDocumentHistory.js`) — one undo/redo stack for text, strokes, erasing and page operations, in the order they happened.

### Adding a handwriting style

1. Put the font in `assets/fonts/`, named after its PostScript name (e.g. `MyHand-Regular.ttf`); add its license to `assets/licenses/` and a row to `assets/licenses/FONTS.md`.
2. `npx react-native-asset` to link it into the Android and iOS projects.
3. `node scripts/extract-font-metrics.js` to measure it.
4. Add one entry to `STYLE_CATALOG` with a `category`, `fontFamily` and `personality`. Size, spacing and variation are derived; the picker, search and tuner pick it up automatically. Tests check the font is bundled, measured, registered on both platforms and licensed.

## Fonts

Dependencies beyond React Native: `@react-native-async-storage/async-storage` (storage), `react-native-safe-area-context` (template) and `react-native-svg` (freehand ink rendering).

30 handwriting fonts, all unmodified from the official Google Fonts repository, under the SIL Open Font License or Apache 2.0. Each font's source, designer and license are listed in `assets/licenses/FONTS.md`, with the license texts alongside.
